# Project 02: Online Food Delivery System (CRAVE)

An artisanal food delivery platform built with **React + Vite + TailwindCSS + Zustand** simulating **Firebase Firestore live listeners & Cloud Functions**.

## 🎨 Distinct Visual Identity
- **Palette**: Warm terracotta (`#ea580c` / `#c2410c`) and comforting cream (`#FFFBF0` / `#ffedd5`).
- **Typography**: Editorial serif headings (`Playfair Display`) paired with clean modern sans-serif.
- **Layout**: Rounded food cards, warm pill filters, hand-drawn vector map with animated courier telemetry.

## 🚀 Full Feature Set Included
- **Restaurant Discovery**: Filter by cuisine (Italian, Japanese, Mediterranean), minimum star rating, and real-time search.
- **Curated Menu Modal**: View dishes, chef's notes, allergens, and price tags.
- **Multi-Restaurant Basket Handling**: Basket logic enforcing single-kitchen integrity with confirmation modal on kitchen switch.
- **Live Order Status Stepper**: Four-phase stepper (*Placed* → *Kitchen Preparing* → *Rider on the Way* → *Delivered*).
- **Delivery Partner Live Map View**: Animated courier icon with live GPS route visualization and courier credentials (vehicle, rating, phone).
- **Two-Way Rating System**: Dual star ratings for both the restaurant kitchen and the delivery courier.
- **Promo Code Engine**: Real-time validation for codes like `CRAVE20` (20% off) and `FREESHIP`.
- **Kitchen Manager Console**: Live prep queue management (start cooking, hand to courier) and real-time menu item creation.
- **AI Dish Photography Generator**: Automated generation of dish photos for items created without images.

## 🛠️ How to Run
```bash
npm install
npm run dev
```
