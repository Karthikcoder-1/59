# Project 20: Travel Booking Platform (WANDERLUST)

Unified global flight, luxury suite, and experiential itinerary booking platform built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Wanderlust Sunset-Gradient UI**: Orange to pink gradient styling (`#f97316` to `#ec4899`, dark slate `#0b1120`, `#1e293b`), smooth destination cards, and airline telemetry.
- **Combined Flight, Hotel & Transfer Search**: Real-time pricing aggregation across Santorini, Kyoto, and Reykjavik.
- **Direct Route Flight Fare Comparison**: Multi-airline schedule comparison with flight durations and ticket classes.
- **5-Star Luxury Resort Showcase**: Verified boutique hotels with amenity badges and per-night rates.
- **Multi-Day Itinerary Builder**: Saved trips dashboard with day-by-day activity timelines and total package billing.
- **Price-Drop Watch & Regional Advisories**: Live notifications on seasonal price drops and weather alerts.

## Getting Started
```bash
npm install
npm run dev
```
