# CINESTREAM // 4K HDR Video Streaming & Creator Cinema

A next-generation video streaming platform built with React, Vite, Tailwind CSS, and Zustand, simulating Firebase Storage uploads and adaptive HLS video streaming.

## 🎬 Core Features
- **Edge-to-Edge Hero Theater**: Full-bleed cinematic banner with Bebas Neue typography and dynamic soundtrack synthesizer toggle.
- **Adaptive-Bitrate Playback Engine**: Simulated HLS streaming with real-time 4K UHD, 1080p, and 720p resolution switching and buffer health telemetry.
- **Parental Control PIN Lock**: 4-digit PIN gate (Default: 1234) for unlocking 18+ and TV-MA content.
- **Continue Watching & Watchlists**: Real-time progress bar tracking and one-click watchlist curation.
- **Creator Upload Studio**: Full studio publishing console with an integrated AI poster generation hook.
- **Subscription Tier Gating**: Badged access tiers (Free, Standard, 4K Ultra VIP).

## 🚀 Quickstart
```bash
npm install
npm run dev
```
