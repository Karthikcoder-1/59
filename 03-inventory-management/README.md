# Project 03: Inventory Management System (TITAN.ERP)

An enterprise-grade multi-facility stock management system built with **React + Vite + TailwindCSS + Zustand** simulating a **Supabase / PostgreSQL relational schema**.

## 🎨 Distinct Visual Identity
- **Palette**: Industrial steel gray (`#0b0f19` / `#1e293b`) with high-visibility safety yellow (`#eab308` / `#facc15`).
- **Typography**: Dense monospace font (`JetBrains Mono`) for telemetry, stock counts, SKUs, and barcodes paired with bold architectural headings (`Space Grotesk`).
- **Layout**: High-density data grid dashboards, audit log ledger, and operational tables.

## 🚀 Full Feature Set Included
- **Multi-Warehouse Stock Tracking**: Real-time stock distribution tracking across Alpha West Port, Beta North Rail, and Central Depot.
- **Low-Stock Threshold Automation**: Visual safety alerts and one-click instant Purchase Order reordering.
- **Barcode & SKU Lookup**: Instant sub-string and numerical barcode scanning filter.
- **Stock Movement Audit Trail**: Tamper-evident ledger recording all Inbound, Outbound, Transfer, and Adjustment actions with timestamps and operator identity.
- **Purchase Order Workflow**: 4-stage lifecycle (*Draft* → *Submitted* → *Approved* → *Received & Restocked*).
- **Turnover & Aging Reports**: Complete inventory valuation, aging days analysis, velocity tier classification, and **one-click exportable CSV file generation**.
- **Role-Based Access**: Toggle between **Warehouse Staff** (adjustments) and **Manager** (PO approvals, reorder authority).

## 🛠️ How to Run
```bash
npm install
npm run dev
```
