# Project 17: Online Banking System (AUREUS Sovereign Vault)

Simulated private online banking and bullion liquidity platform built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Vault-Like Charcoal & Metallic Gold UI**: Dark luxury fintech aesthetic (`#0c0a09`, `#1c1917`, `#d97706`, `#fbbf24`), Cinzel typography, and precision card grids.
- **Consolidated Liquidity Dashboard**: Checking, Bullion Reserve, and Municipal Treasury Bond accounts with real-time balance aggregation.
- **Encrypted Fund Transfers & Wires**: Authenticated transfers between accounts with simulated 6-digit Time-Based One-Time Password (TOTP) 2FA.
- **Bill Pay & Utility Dispatches**: Payee management, recurring bill scheduling, and instant reconciliation.
- **Collateralized Credit Facilities**: Loan management dashboard, fixed APR breakdown, and instant credit underwriting submission.
- **Reconciled Transaction Ledger**: Filterable transaction history with downloadable PDF statement export simulation.

## Getting Started
```bash
npm install
npm run dev
```
