# Project 16: Content Management System (THE GAZETTE CMS)

Editorial newspaper-inspired content management system and publishing workbench built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Editorial Newspaper UI**: Monochrome paper/ink base (`#fcfbf9`, `#141414`) with signature blood-red rule line (`#990000`), Playfair Display serif typography, and multi-column article preview.
- **Reusable Block Builder**: Headline, Lead Callout, Pull Quote, and Rich Body Copy inserter.
- **Publishing Workflow Pipeline**: Kanban stage tracking (Drafts → In Review → Published to Print).
- **SEO & Search Graph Studio**: Live Google SERP preview, meta title/description manager, keyword density checker.
- **Immutable Version Ledger**: Revision timestamps, author attribution, and revision rollback.
- **Readership & Circulation Analytics**: Total impressions, unique readers, average read time, and reader retention metrics.

## Getting Started
```bash
npm install
npm run dev
```
