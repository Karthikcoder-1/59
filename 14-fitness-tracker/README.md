# Project 14: Fitness Tracker (PULSE Kinetic)

High-performance kinetic fitness tracker and bio-telemetry analytics dashboard built with React, Vite, TailwindCSS, and Zustand.

## Features
- **High-Energy Kinetic UI**: Neon orange-on-black theme (`#ff5500`, `#09090b`), bold condensed typography, circular progress metrics.
- **Live Telemetry & Gauge Rings**: Real-time steps, active caloric burn, kinetic minutes, recovery readiness index.
- **7-Day Energy Histogram**: Weekly training volume and strain distribution analytics.
- **Adaptive Bio-Advisor**: AI recommendation engine surfacing load balancing, myofascial recovery, and aerobic capacity tips.
- **Exercise Matrix & Workout Logging**: Searchable tactical movement library with MET ratings, sets/reps/RPE logs.
- **Nocturnal Sleep Staging & HRV Dynamics**: Sleep architecture breakdown (Deep, REM, Light) and parasympathetic tone tracking.
- **Wearable Bio-Sync Simulator**: Simulated Bluetooth integration with Garmin/Apple Watch/Whoop telemetry.

## Getting Started
```bash
npm install
npm run dev
```
