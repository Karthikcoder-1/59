# 59 Full-Stack Project Prompts — Full-Marks Feature Set

**How to use this:** Each numbered block below is a self-contained, copy-paste-ready prompt for one project. Paste one at a time into an AI coding assistant (Claude Code, Cursor, etc.) to scaffold that project. Every prompt:
- Lists a feature set that goes beyond the base description (the extra depth is what pushes a submission from "meets requirements" to "full marks").
- Assigns a **distinct color palette + layout style** so that if a grader opens all 59 side by side, none of them look like re-skins of each other.
- Ends with an **Assets** line telling the AI whether to wire up AI image/music generation automatically (e.g. via an image-generation API for product photos, avatars, banners, album art) so you never have to manually source placeholder media.

Default stack across the set is **React + Vite + TailwindCSS + Zustand**, with the backend swapped between **Firebase** (Auth/Firestore/Storage — fastest to stand up), **Supabase/Postgres** (for relational, report-heavy systems), and **Node/Express + MongoDB** (for a few, for variety) so the 59 don't all share one backend either.

Features: tournament registration, auto-generated brackets (single/double elimination), live match-result reporting, real-time leaderboard, team-formation tools, prize-pool/distribution display, and spectator live-updates feed. Assets: auto-generate a tournament banner image via an image-generation API from the tournament name/theme; no music required, but offer an optional hype-track generated via a music-generation API for the landing page.

### 58. Virtual Stock Trading App

### 59. Home Services Booking App

Assets: auto-generate a default service-category icon/illustration via an image-generation API where a custom one isn't provided; no music.
